# Galeria de Atores e Atrizes - Checkpoint 2

## Sobre o Projeto
Este projeto é uma aplicação web desenvolvida para o Checkpoint 2 da disciplina de Application Development da FIAP. O objetivo principal é renderizar dinamicamente uma lista de atores e atrizes na tela a partir de um arquivo de dados (`dados.js`), exibindo informações como foto, nome, país e data de nascimento em uma estrutura de grid.
